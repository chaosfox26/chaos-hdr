# Chaos HDR website

## Platform
web

## Purpose
Give shared links a readable Chaos HDR title, short description and the approved neon lightning image. Help visitors understand the project and reach the latest installer, documentation and source.

## Audience and mechanism
Linux players evaluating experimental NVIDIA HDR and sharpening. The effect processes approved window output in KDE/KWin, without injecting into games. Tests cover an existing CachyOS installation with KDE Plasma Wayland. Other distributions and GNOME are untested. Physical fresh-system installation remains unverified.

## Confirmed commitments
The user requested the landing page, shorter repository description and new social image, following the proposed GitHub Pages approach. Preserve the magenta, electric-blue, black and white brand, glitch lettering and lightning. Keep code minimal, fast and stable, with explanations in documentation. Work solo and complete privacy checks before pushing.

## Implementation choice
Plain static HTML/CSS and a small optional clipboard script follow the requested minimal-code approach. This is a scoped implementation choice, not a saved framework preference. The site must work without JavaScript. Use the permanent latest-release installer URL.

## Evidence
README.md and docs/performance.md contain the published measurement scope. docs/images/chaos-hdr-sidebar.png is the previously reviewed synthetic-session capture. site/assets/chaos-hdr-social-preview.jpg is the approved generated artwork; no private desktop captures belong here.
