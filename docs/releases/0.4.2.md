# Chaos HDR 0.4.2 — overlay rendering fix

**[Download Chaos-HDR-CachyOS.run](https://github.com/chaosfox26/chaos-hdr/releases/download/v0.4.2/Chaos-HDR-CachyOS.run)**

Or install with one terminal command:

```sh
curl -fsSL https://github.com/chaosfox26/chaos-hdr/releases/download/v0.4.2/install.sh | bash
```

## What changed

Fixed black rectangles replacing the sidebar's title, text, sliders and buttons.
An emoji in an application title could select a color bitmap font that the
overlay's font builder cannot load, invalidating the entire font texture.
Shared OpenGL pixel-unpack state could independently corrupt a rebuilt texture.

Fallback selection now accepts supported outline fonts, rolls back failed font
builds and isolates pixel-unpack state during font uploads. Unsupported symbols
may use a missing-character glyph while the rest of the interface stays readable.
The existing neon title, lightning, layout and motion are preserved.

The direct-buffer HDR processing, shaders, synchronization and GPU recovery are
unchanged. This fix adds no HDR pass, frame copy or GPU wait. Upload-state checks
run only when the font texture needs creation; a normal visible frame adds one
texture-presence check. A closed sidebar performs no overlay rendering.

The [1440p and 4K measurements](../../README.md#tested-gpu-processing-time) were
taken with 0.4.0. They remain the processing baseline, not new 0.4.2 benchmarks.

## Validation

- Reproduced both font failures, then checked exact uploaded atlas pixels on
  OpenGL and OpenGL ES, including repeated rebuilds, emoji and failure rollback.
- Passed isolated KDE checks for multilingual text, clipboard, sliders,
  independent effect toggles, application selection and sidebar motion.
- Visually verified the production fix on the existing KWin 6.8.1 desktop,
  including closing and reopening the sidebar. Settings and the compositor
  session were preserved.
- Added a development-only font-texture regression check and refreshed the
  interaction fixture's layout before testing controls after profile changes.

The supported target remains CachyOS/Arch with KDE Plasma Wayland, a compatible
NVIDIA RTX GPU/driver and an HDR display enabled in KDE. Fresh-system installation,
startup after a new login and a complete hosted-release upgrade remain unverified.
This remains an experimental source release. See [installation](../installation.md).

## Release files

- `Chaos-HDR-CachyOS.run`: self-extracting source installer.
- `Chaos-HDR-CachyOS-source.tar.gz`: matching reviewed source.
- `install.sh`: downloads, verifies and runs the packaged installer.
- `SHA256SUMS`: checksums for those three files.

The installer builds locally and preserves existing profiles and application
approvals. Personal settings, live desktop captures, diagnostics, compiled
binaries and installed dependencies are excluded. The previously reviewed
documentation images are unchanged. Original source remains GPL-2.0-only;
third-party licenses and the combined-binary distribution boundary are unchanged.
