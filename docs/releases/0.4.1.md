# Chaos HDR 0.4.1 — packaged installer

**[Download Chaos-HDR-CachyOS.run](https://github.com/chaosfox26/chaos-hdr/releases/download/v0.4.1/Chaos-HDR-CachyOS.run)**

Or install with one terminal command:

```sh
curl -fsSL https://github.com/chaosfox26/chaos-hdr/releases/download/v0.4.1/install.sh | bash
```

## What changed

0.4.1 is published as a regular GitHub release so it appears as the latest
release on the repository page. The source, installer manifest and updater
metadata all identify 0.4.1 with the same release status. Existing 0.4.0 assets
are preserved.

The README now includes the animated neon title, a screenshot of the current
interface and measured GPU processing times at 1440p and 4K, with overlay drawing
reported separately. The development credits are updated.

The HDR processing, GPU synchronization, overlay, settings and dependencies are
unchanged from [0.4.0](0.4.0.md). This packaging update adds no per-frame work.
The installer still downloads upstream dependencies, builds locally and
preserves existing picture profiles and application approvals on reinstall.

## Requirements and validation

The supported target is CachyOS/Arch with KDE Plasma Wayland, a compatible
NVIDIA RTX GPU/driver and an HDR display enabled in KDE. Missing build packages
may require administrator authentication.

This project remains experimental. Regular GitHub release status does not
certify fresh-system installation, startup after a new login or a full
hosted-release upgrade; those acceptance tests remain outstanding. Automated
source and package checks do not replace them. See the
[installation guide](../installation.md) and [0.4.0 validation notes](0.4.0.md).

## Release files

- `Chaos-HDR-CachyOS.run`: self-extracting source installer.
- `Chaos-HDR-CachyOS-source.tar.gz`: matching reviewed source.
- `install.sh`: downloads, verifies and runs the packaged installer.
- `SHA256SUMS`: checksums for those three files.

Personal settings and captures, compiled native binaries and installed dependencies
are excluded. The documentation images use an isolated synthetic test window.
Original source remains GPL-2.0-only; upstream licenses and the
existing combined-binary distribution boundary are unchanged.
